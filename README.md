# StagePass — Concert & Event Booking Website

A responsive React + Vite frontend for discovering events and making demo ticket bookings.

## Features
- Responsive landing page and event discovery grid
- Search by event, artist, venue, or category
- Filter by event category and city
- Ticket selection for General, Premium, and VIP
- Demo booking confirmation and booking count
- Newsletter signup interaction
- Mobile navigation

## Run locally
1. Install Node.js (LTS).
2. Extract this project folder.
3. Open the folder in VS Code.
4. Open Terminal and run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Important
This is a frontend demo. Event details are sample data, booking confirmations are not sent to a server, and no real payment is collected. For production, connect a backend/database, authentication, verified event inventory, and a payment provider.
